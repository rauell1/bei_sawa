# Governance submission description

BeiSawa means “fair price.” It is a Governance-track prototype under the Financial services / Value for money theme, with Makueni County Government’s internal audit function as its proposed institutional use case: reviewing completed procurement records. It prepares a sourced file for human review; it never awards, cancels or submits a tender. No institutional deployment or measured time savings are claimed.

The current scope is published tender and award records, not bid evaluation. Procurement portals generally do not publish the bid documents needed for full committee work. Four clearly labelled synthetic OCDS-shaped records demonstrate the workflow. Synthetic data is permitted by the supplied challenge brief; historical records are an optional future extension, subject to source, licence and personal-data review.

BeiSawa’s own MCP server exposes four reusable tools: search records, retrieve a source record, calculate deterministic review signals and write a citation-validated draft. The borrowed official filesystem MCP server reads a directory-scoped review playbook; reusing it avoids rebuilding established MCP file-reading machinery. LangGraph provides open-source orchestration. Qwen 2.5 chooses state-valid tools within a bounded loop, checks evidence, retries failed reads and abstains when evidence remains thin. Stub mode is explicitly labelled.

Every signal carries dataset-scoped identifiers and JSON Pointer citations. Draft creation recomputes the analysis and rejects altered evidence. The current checks compare a first award with its recorded tender estimate and flag limited recorded competition. They do not establish wrongdoing, market price, budget compliance or unpaid-invoice exposure.

Neon Auth, private storage and Postgres support individual workspaces. A named officer approves the exact content hash before an immutable internal report can be filed. Model tools cannot approve. Logged calls retain inputs, outputs, timestamps and failures. Evaluation includes real local Qwen runs, refusal cases and an unfixed limitation in tool-choice explanations. The live-run video shows actual inference and handover; production approval and computer-hosted inference still need verification. Source code uses MIT; model weights retain their separate licence.
